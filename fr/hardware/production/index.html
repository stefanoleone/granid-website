Matériel recommandé

Apportez votre propre Mac. Nous recommandons les spécifications.

Le matériel n'est inclus dans aucun plan. Granid tourne sur un Mac qui vous appartient et reste dans vos locaux. Ci-dessous : les spécifications que nous recommandons pour que le logiciel tourne confortablement avec toutes les fonctionnalités activées.

Vous acquérez le Mac via le canal de votre choix : Apple, revendeur agréé ou reconditionné. Nous émettons la licence et vous envoyons le paquet d'installation ; vous l'exécutez sur le Mac.

Essential & Professional

Apple Silicon, 64 Go de mémoire unifiée (par exemple un Mac mini ou un MacBook Pro). Couvre un professionnel sur Essential, jusqu'à quatre sur Professional.

Enterprise

Apple Silicon, 128 Go de mémoire unifiée (un MacBook Pro avec M5, ou un Mac Studio). Dimensionné pour les grandes études, environ 15 professionnels sur une même instance.

macOS 26 Tahoe

Requis pour que tout le traitement de Granid reste sur l'appareil.

Pourquoi 64 Go de mémoire unifiée

Les plans payants gardent chaque composant de Granid sur votre Mac : la recherche dans les documents, la compréhension du langage et votre index documentaire. 64 Go est le plancher qui permet à tout cela de tourner aux côtés de macOS, votre navigateur et l'analyse documentaire sans ralentir. Les instances Enterprise partagées, plus grandes, passent à 128 Go pour servir davantage de professionnels à la fois.
