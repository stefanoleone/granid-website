Hardware: Trial

Granid auf Ihrem
bestehenden Mac.

Während der 2-wöchigen Testphase brauchen Sie keine neue Hardware. Granid läuft auf jedem modernen Apple-Silicon-Mac. Der Mac Mini M4 Pro ist erst beim Wechsel auf einen Bezahltarif erforderlich.

Trial starten

Apple Silicon

M1, M2, M3 oder M4. Intel-Macs werden nicht unterstützt.

8 GB Unified Memory

Mindestens. 16 GB sind komfortabel, aber für den Trial nicht erforderlich.

macOS 14 oder neuer

Sonoma oder neuer. Ventura und ältere Versionen werden nicht unterstützt.

Warum ein Mac mit Standardausstattung genügt

Während des Trials erledigt die Granid-App auf Ihrem Mac nur den Dokumentenimport und die Basisindexierung. Die rechenintensive Verarbeitung (das Verstehen Ihrer Dokumente und das Generieren von Antworten) läuft auf einem von Granid betriebenen Remote-Dienst. Genau dadurch können Sie das Produkt evaluieren, ohne Produktions-Hardware kaufen zu müssen.

Wichtig: Trial-Daten verlassen Ihr Büro

Während der zweiwöchigen Testphase werden die von Ihnen eingereichten Dokumente und Anfragen auf einem von Granid betriebenen Remote-Dienst verarbeitet. Das heisst: Die Daten verlassen während des Trials Ihren Mac. Das ist das Gegenteil des Bezahlprodukts, bei dem nichts das Büro verlässt. Verwenden Sie im Trial bitte ausschliesslich nicht-sensible oder anonymisierte Daten.

Die Bezahltarife laufen vollständig lokal auf einem Mac Mini M4 Pro in Ihrem Büro. Keine Mandantendaten verlassen das Gebäude.

Bereit für die Produktion?

Bezahltarife laufen auf einem dedizierten Mac Mini M4 Pro (64 GB), installiert in Ihrem Büro. Sämtliche Verarbeitung bleibt auf dem Gerät. Nichts verlässt das Gebäude.
